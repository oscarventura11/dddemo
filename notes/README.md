# Zettelkasten Vault

This folder is an Obsidian-ready Zettelkasten vault for the project.

## Folder map

- `00 Inbox`: unprocessed captures.
- `10 Fleeting`: quick thoughts to refine or discard.
- `20 Literature`: notes from books, talks, docs, and articles.
- `30 Permanent`: atomic evergreen notes.
- `40 Structures`: maps of content (MOCs), indexes, and topic outlines.
- `50 Projects`: project-scoped plans and execution notes.
- `90 Attachments`: files and images.
- `99 Templates`: note templates.

## Naming

Use timestamp IDs for durable linking:

`YYYYMMDDHHmm-title.md`

Example:

`202606301430-policy-whitelist-risks.md`

## Core flow

1. Capture in `00 Inbox`.
2. Refine to `10 Fleeting` or `20 Literature`.
3. Promote key ideas to `30 Permanent`.
4. Link from one or more `40 Structures` notes.
